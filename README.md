專案名稱： G67_刷錫穩定性提升_殘錫改善
改善問題： 局部錫量異常導致3DL Tilt y/SPI Area/Height良率異常
         經過異常品分析對應刮刀行走路線，異常集中在刮刀行徑路線板子邊緣，對照鋼板上殘錫狀況有高度連結性
目前作法：刷錫完成直接刮刀直接提高旋轉方式，隨著時間刮刀上錫膏會滴落於鋼板功能區上，隨著鋼板孔洞滲到鋼板背部與登板上
創新方案：修改刮刀滑行距離有0-->10mm避開殘錫滴落到功能區
相關數據：參數修正後生產>200 pcs 未發現相同異常導致SPI/Tilt NG
預期效益： 此異常在先前約有~0.5%整體良率異常，修正後無相同異常再發
