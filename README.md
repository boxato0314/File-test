A.改善問題：局部錫量異常造成 SPI Area／Height 及 3DL Tilt Y 良率波動。異常品分析顯示，不良主要集中於刮刀行進路線靠近板邊區域，並與鋼板功能區殘錫及背部滲錫現象高度相關。

B.營業秘密特徵：原刷錫完成後刮刀直接抬升旋轉，刮刀殘留錫膏可能滴落於鋼板功能區。本案將刮刀滑行距離由 0 mm 調整為 10 mm，使抬升位置避開功能區，降低殘錫經鋼板孔洞滲至背部及PCB表面的風險。

C.效益：參數修正後已生產超過 200 pcs，未再發現相同異常造成 SPI 或 Tilt NG。依先前此異常約影響整體良率 0.5% 推估，改善後可避免約 0.5% 良率損失。

D.保密考量：刮刀滑行距離、抬升位置、殘錫形成機制、鋼板功能區避讓邏輯及驗證條件，屬刷錫製程參數與設備動作整合 Know-how，應限制存取並納入機密與版本管制。
