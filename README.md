版面與頁數補充要求

1. 各 Agenda 主題不限制只能一頁。
    應依資料量、圖片數量、流程複雜度與可讀性，自行拆分為多頁；但所有頁面標題仍須歸屬於以下固定分類，不得新增或更改主分類名稱：
    A. 背景說明及問題描述
    B. 創新特徵及內容描述
    C. 效益說明
    D. 以營業秘密保護之考量
    Summary
    同一分類超過一頁時，可使用「A-1、A-2」、「B-1、B-2」等頁次標示，或在固定分類標題下增加副標題，例如：
    「A. 背景說明及問題描述｜不良現象」
    「A. 背景說明及問題描述｜原因分析」
    但不得改變主分類名稱。
2. 先完成內容規劃，再進行整體排版整理。
    所有內容、圖片、圖表及流程圖完成後，必須再執行一次全簡報排版優化，不可僅逐頁新增內容而未進行整體整理。
3. 完成前須逐頁進行視覺檢查與修正，至少包含：
    * 版面是否置中，左右留白是否平衡
    * 文字框是否超出外框或頁面
    * 文字是否遭裁切、重疊或被圖片遮擋
    * 圖片比例是否正常，避免拉伸變形
    * 圖片、文字框、圖表是否對齊
    * 各區塊間距是否一致
    * 標題、內文、註解字級是否一致
    * 內文字體原則上介於 8–14 pt，避免低於 8 pt
    * 頁碼、Ennostar Logo、Confidential 頁尾是否完整保留
    * 所有頁面是否維持相同視覺語言與配色邏輯
    * 非異常、警示、NG或風險內容不得使用紅色
    * 一般圖示、編號、流程箭頭及裝飾元素應優先使用深藍、淺藍、灰色或青綠色
4. 排版不足時，優先增加頁數，不得以縮小字體方式硬塞內容。
    當單頁內容過多、圖片過小或文字低於 8 pt 時，應主動拆分頁面，確保簡報可讀性。
5. 圖片與圖表配置原則：
    * Before／After 圖片應清楚標示並盡量並列比較
    * 原始附件可裁切、放大重點區域及增加可編輯註解
    * 代表性數據應優先轉為可編輯圖表、數據卡或比較圖
    * 不得以大段文字取代可視化內容
    * 圖片解析度不足時，不得過度放大造成模糊
6. 最終交付前必須完成一次簡報輸出預覽檢查。
    將PPT轉為PDF或逐頁圖片檢視，確認沒有偏左、偏右、超框、裁切、字型替換、頁尾遺失及圖表跑版後，才可提供最終檔案。
